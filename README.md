# Matryoshka Codec

Hide nested messages inside one visible emoji using Unicode variation selectors.

Live test page:

```text
https://thealch3m1st.github.io/matryoshka-codec/
```

Local development:

```bash
npm install
npm run dev
```

Checks:

```bash
npm test
npm run lint
npm run build
```

The app currently supports nested shells, text, compact voice recipes, links,
images, audio, video, and common streaming embeds.
